# Documentation site

Docusaurus site for Prometheus Parking Lot, themed with the know-me brand tokens
(Flat 2.0). Commands, publication URL and verification are documented in
[`docs/contributing/docs-site.md`](docs/contributing/docs-site.md).

```bash
npm ci && npm run build   # sanitizer + production build
npm run verify            # full gate: links, screenshots, tokens, Flat 2.0, a11y
```
