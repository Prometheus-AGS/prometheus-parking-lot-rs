## Recommendation and uncomfortable constraint

Apply one coherent amendment: defer actual history purge/cache removal and credential/signer rotation; certify blocking current-candidate/package containment controls plus truthful retained-history audits; use GitHub-hosted native OS jobs for automated profiles and separately attributable manual macOS GUI and quiet-machine evidence. Preserve all seventeen scenario IDs and every other production oracle, real backend, signing, protected-environment, review and OIDC requirement.

JSON alone cannot implement this. The current source enforces revision 1, schedules every profile/collector on self-hosted labels, requires a same-run artifact for every profile, demands completed purge evidence for G-02, and cannot see local manual paths on ephemeral hosted machines. An amended contract without these source changes stays BLOCKED. Accepting the recommendation authorizes scope; it supplies none of the required observations.

Keep compact protocol version 1 and its exact two files. Keep gate name `G-02` to avoid a parallel certificate schema, but explicitly redefine its meaning for the new contract as an independently attributable acknowledgement of deferred history cleanup plus observed retained-scan outcomes. A G-02 PASS under the new digest means this amended gate passed; it must never mean purge/cache removal or clean history. The old contract and old receipts retain their original meanings. If that semantic reuse is undesirable, renaming/removing G-02 requires simultaneous consumer/schema/fixture changes and is a larger amendment.
