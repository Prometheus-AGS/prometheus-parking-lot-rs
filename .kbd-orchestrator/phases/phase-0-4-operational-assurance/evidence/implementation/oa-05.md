## Authored real-path oracles

The fixture copies the **complete actual documents** and unchanged detector
configuration into a temporary real Git repository. It uses no scanner mocks
or failure shims. The tracked source contains no complete secret-like canary:
synthetic values are assembled from hashes of non-secret fixture labels at
runtime. The default-rule control has no custom-rule prefix.

Every invocation uses real gitleaks with the copied config, `--redact=100`,
JSON reporting and `--exit-code=10`. The finding exit override applies only
inside the disposable fixture; production exit behavior is unchanged. A
negative case requires exit 10 plus the required RuleID and expected path in
the actual report, so a generic scanner error is insufficient.

| Case in the authored suite | Required oracle, not observed output |
|---|---|
| Actual examples, tree scan | `detect --no-git --source .` exits 0 |
| Actual examples, staged scan | `git --pre-commit --staged .` exits 0 |
| Actual examples, committed range | `git --log-opts="$baseline..HEAD" .` exits 0 |
| Canary outside example paths | Exit 10; `sk-prefixed-api-key`; `production/prefix-control.txt` |
| Separate default-rule canary | Exit 10; `generic-api-key`; `production/default-control.txt` |
| Canary appended inside coding-standards document | Exit 10; `sk-prefixed-api-key`; exact document path |
| Canary appended inside E2B document | Exit 10; `sk-prefixed-api-key`; exact document path |
| Clean worktree with canary retained only in index | Tree scan exits 0 |
| Same staged-only canary | Staged scan exits 10 with custom rule and `production/staged-control.txt` |
| Same canary committed into range | Range scan exits 10 with custom rule and `production/staged-control.txt` |

These define ten assertions, including the two iterations over the example
paths. Both raw stdout/stderr and JSON are inspected for the full synthetic
values before emission; detected unredacted values stop without printing the
offending artifact. Read/filter failures also fail. The fixture prints its
working directory, exact expanded command, actual exit/oracle disposition and
redacted finding reports. Its owned temporary files are removed on exit;
capture emitted logs externally at the final boundary.

The custom/default controls address the requested lost-detection scenario.
Canaries inside both example paths reject broad path exclusions. The staged
control addresses the specific failure where a clean working copy conceals
a secret still in the index. Redaction guards protect the scanner-output
boundary required by OA-05. None introduces a rotation prerequisite.

[gitleaks v8.30.1 Git command source](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/git.go),
