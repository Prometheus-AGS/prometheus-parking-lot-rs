These are authored **unexecuted** entry points. Their placeholders are supplied
by the OA-18 owner after the clean candidate and environment are prepared:

```bash

  --case "$CASE_ID" --output "$OA12_PACKET/$CASE_ID"

  --receipts "$OA12_PACKET" --candidate "$FROZEN_CANDIDATE" \
  --output "$OA12_SUMMARY"
```

Execute `run` for every one of the 52 checked IDs, not one illustrative case.
All outputs are private fresh external paths. The runbook supplies the exact
expanded Cargo build/list/run forms and upgrade image arguments. Cargo is
serialized within an invocation; normal/mutant target directories and flags
are isolated. All normal oracles and companions must pass; each mutant must
fail only the named source oracle and retain passing unaffected companions.

Native/redb/PG/Iggy/Loom require a separate successful build, actual nonzero
JSON listing with exact oracle/companion identities, then nextest **100** plus
one named FAIL, one-test summary, panic and diagnostic for each mutant oracle.
Normal and companion runs require 0 plus the named PASS/one-test summary.
Browser requires separate successful wasm build, exact actual 15/6 export
listing, real headless Chrome invocation and exactly one selected result:
Cargo **101**, per-test **FAIL**, 0 passed/1 failed and named diagnostic for
mutants; 0/`ok` for normal and companions. No Node-only substitute is accepted.
Upgrade requires a prebuild/list of its exact single oracle in both cfg modes,
then owner wrapper **0** plus actual inner nextest **100**, one discovered named
FAIL/panic/seeded-result assertion and `EXPECTED_FAILURE` for the mutant.
Normal must perform the real populated upgrade, independent restored backup
and successful PG suites. Wrong diagnostics, compilation errors, empty or
missing discovery, backend setup errors or watchdogs never count as detection.

After accepting the whole real packet, aggregate removes one actual row and
requires the same completeness predicate to reject `OA-12:omission`. It also
substitutes the actual same-oracle normal PASS result, with its observed 0
exit/logs, into the same expected-mutant classifier; it must reject `OA-12:exit`.
This is a real-output verifier control, not a fabricated mutant PASS claim or
a separate mocked test suite. Both rejection receipts and raw-log references
must appear in the final aggregate.
